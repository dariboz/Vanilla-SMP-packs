# Vanilla SMP — Resource Packs

Distribution repo for the [Vanilla SMP](https://github.com/dariboz) network's server resource packs.

- **`packs.yml`** — the machine-readable manifest consumed by the *VanillaSMP-RPManager*
  plugin. Each pack entry carries its stable **UUID**, download **URL** and **SHA-1** —
  Minecraft clients cache server packs by UUID + hash, so unchanged packs are never
  re-downloaded. Regenerated by tooling on every release.
- **Releases** — built pack zips only; no sources.
  - the **`dev`** release is the mutable dev channel (assets are replaced in place), and
  - **version tags** are immutable production releases.

Resource packs are assets only — no executable code. Each pack remains licensed by its own
terms as embedded inside it.
